# Elo 8 — Gestão de Metas da Rede INOVA

Sistema de gestão de atividades, metas, tarefas e agenda do Centro Regional de Inovação.

- **Acesso:** https://inovaembrusque-cpu.github.io/elo8/
- **Dados:** planilha "Elo 8 — dados (não editar)" na conta inovaembrusque@gmail.com (Google Apps Script).
- **Agenda:** compromissos e atividades importantes vão para a Google Agenda de inovaembrusque@gmail.com, com convite para gestao@inovaembrusque.com.br.
- **Aplicativo:** abra o link no celular ou no computador e use "Instalar app".

`Codigo.gs` é uma cópia do código do servidor (Apps Script). As senhas ficam apenas na planilha, em forma de hash.
